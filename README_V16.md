# Humanity AI Circle V16 — UX + Research + Mobile Final

V16 is the launch-oriented consolidation of the Humanity AI Circle work from V2 through V15. It does **not** change the community thesis. It improves hierarchy, research credibility, cross-page flow, accessibility, and mobile responsiveness.

## Core message

- **Don’t figure out AI alone.**
- **People helping people through the AI transition.**
- **People lead. AI helps.**
- **Outcome first. Tool second. Brand last.**
- **Meet. Talk. Learn. Build. Belong.**

## Run locally

Open `index.html` directly or run:

```bash
node server.js
```

Set a custom port with `PORT=8123 node server.js`.

## Important production step

The final public domain has not been supplied, so V16 does not invent canonical URLs. Follow `DEPLOYMENT_CHECKLIST_V16.md` before publishing.
