# V16 Deployment Checklist

Before public deployment:

- Replace `PUBLIC_BASE_URL` in `sitemap.xml.template`, save as `sitemap.xml`, and add its absolute URL to `robots.txt`.
- Add absolute canonical URLs to every substantive page after the final public domain is confirmed.
- Replace relative Open Graph image paths with the final absolute production image URL.
- Test iOS Safari and Android Chrome on real devices.
- Confirm WhatsApp, YouTube, Instagram and email destinations.
- Add real event/community activity only when it exists; do not fabricate dates, members or outcomes.
