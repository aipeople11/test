# WhatsApp sharing setup

This build is preconfigured for the GitHub Pages URL:

- Site: https://aipeople11.github.io/HumanityAIcircle/
- Preview image: https://aipeople11.github.io/HumanityAIcircle/assets/share-card.png

The Open Graph image is 1200 x 630 and is embedded in the package at `assets/share-card.png`.

For WhatsApp previews to work, the GitHub Pages site and image must be publicly accessible over HTTPS. After deployment, open the image URL directly in a browser to confirm it loads. WhatsApp may cache older previews, so a newly deployed preview can take some time to refresh.

If the production domain changes later, replace the absolute `og:image`, `twitter:image`, `og:url`, and canonical URLs with the new public domain.
