# Humanity AI Circle V16.1

Visual-storytelling refinement of V16. The strategy is unchanged; the homepage is now a guided three-chapter experience rather than a stack of similarly weighted cards.

## Start locally

```bash
node server.js
```

Then open `http://localhost:8080` unless the `PORT` environment variable is set.

The site can also be hosted as static HTML/CSS/JS. The optional `/api/trace` endpoint requires the bundled Node server or equivalent backend support.

## Main homepage story
1. **YOU** — transition, personal question, clearer next step, information overload.
2. **PEOPLE** — need/help exchange, human connections, recurring meetings, outcome-first use.
3. **PROOF** — research signals, evidence maturity, founder credibility, human control, roadmap and trust.

## Founder/origin
V16.1 now states the user-supplied operating basis directly: the people behind the Circle work on enterprise AI use cases, build AI applications and run an applied research lab. The community is framed as a response to the practical gap they observed between rapidly increasing AI capability and fragmented human clarity.
